Project Rules — Vinhomes Grand Park Landing Page
Mục tiêu

Xây dựng một Landing Page bất động sản giới thiệu và quảng bá Vinhomes Grand Park tại Thành phố Thủ Đức.

Trang phải có giao diện hiện đại, cao cấp, rõ ràng, responsive và tập trung vào chuyển đổi người dùng thông qua CTA.

Công nghệ bắt buộc

Chỉ sử dụng:

HTML5

CSS3

JavaScript thuần

Bootstrap qua CDN

Không sử dụng:

React

Vue

Angular

jQuery

Tailwind CSS

PHP

Python

Node.js backend

Database

Bất kỳ framework backend nào

Mã nguồn cuối cùng phải chạy trực tiếp bằng cách mở index.html trên trình duyệt.

Cấu trúc file

Mã nguồn chính bắt buộc nằm tại:

index.html

CSS riêng nằm tại:

css/style.css

JavaScript riêng nằm tại:

js/script.js

Không nhúng một lượng lớn CSS hoặc JavaScript trực tiếp vào index.html nếu có thể đặt chúng vào file riêng.
